# pucia-protocol.github.io

Root of the PUCIA website. It only redirects to the site itself and tells search engines where the sitemap is.

- Website: https://pucia-protocol.github.io/pucia/ (English) and https://pucia-protocol.github.io/pucia/fr/ (français)
- Protocol repository: https://github.com/pucia-protocol/pucia

## Files

| File | Purpose |
|---|---|
| `index.html` | Redirects to `/pucia/` |
| `robots.txt` | Read by search engines at the root of the host; points to the sitemap |
| `5a7d2c4bd6dcc42c9f80661cdcf861af.txt` | IndexNow key file: proves that page submissions to search engines come from this site. It is public by design. |
